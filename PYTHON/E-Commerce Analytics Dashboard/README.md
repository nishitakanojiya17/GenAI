# 🛒 E-Commerce Sales Analytics Dashboard

An interactive data analytics dashboard built using **Python, Pandas, NumPy, Plotly, and Streamlit** to analyze and visualize Amazon e-commerce sales data.

The project performs data cleaning, exploratory data analysis, statistical analysis, and interactive visualization to identify sales trends, product performance, customer/business patterns, and regional insights.

---

## 📌 Project Overview

The **E-Commerce Sales Analytics Dashboard** is designed to transform raw Amazon sales data into meaningful business insights.

The project covers the complete data analytics workflow:

- Data Cleaning
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Interactive Dashboard
- Business Insights

The dashboard allows users to interactively filter and explore sales data based on different categories, fulfilment methods, states, B2B transactions, and date ranges.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall e-commerce sales performance.
- Identify top-performing product categories.
- Analyze monthly and yearly sales trends.
- Understand regional/state-wise sales performance.
- Analyze order status distribution.
- Compare B2B and non-B2B sales.
- Analyze fulfilment methods.
- Identify top-performing SKUs.
- Understand product size distribution.
- Study the relationship between quantity sold and revenue.
- Present insights through an interactive dashboard.
