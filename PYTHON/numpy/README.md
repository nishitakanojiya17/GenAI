# NumPy Practice Folder

This folder contains beginner-friendly NumPy examples and a notebook for learning array operations.

## Files

- `numpy_basics.ipynb` - interactive notebook for learning NumPy
- `program_1_arrays.py` - array creation and indexing
- `program_2_statistics.py` - mean, median, standard deviation, min/max
- `program_3_matrix_operations.py` - matrix multiplication and reshaping
- `requirements.txt` - NumPy dependency

## Run the examples

```bash
pip install -r requirements.txt
python program_1_arrays.py
python program_2_statistics.py
python program_3_matrix_operations.py
```
