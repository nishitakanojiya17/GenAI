# AI-Powered Fraud Detection System

An end-to-end Machine Learning project for detecting potentially fraudulent financial transactions using classification models, imbalanced-data techniques, explainable AI, and an interactive Streamlit dashboard.

---

## 📌 Project Overview

Financial fraud detection is a challenging machine learning problem because fraudulent transactions are extremely rare compared to legitimate transactions.

This project develops a machine learning system that:

- Analyzes transaction data
- Performs exploratory data analysis
- Handles highly imbalanced classes
- Performs feature engineering and preprocessing
- Trains and compares multiple machine learning models
- Evaluates models using fraud-focused metrics
- Optimizes the classification threshold
- Uses SHAP for model explainability
- Provides an interactive Streamlit interface for predictions

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand transaction patterns and class imbalance.
2. Build a reliable fraud classification pipeline.
3. Compare multiple machine learning algorithms.
4. Reduce the impact of class imbalance.
5. Evaluate the model using appropriate classification metrics.
6. Explain individual model predictions using SHAP.
7. Deploy the trained model through a Streamlit application.

---

## 📊 Dataset

The project uses the **Credit Card Fraud Detection dataset** containing:

- 284,807 transactions
- 492 fraudulent transactions
- 30 input features plus the target variable
- Highly imbalanced target classes

The target variable is:

0 → Legitimate Transaction
1 → Fraudulent Transaction
